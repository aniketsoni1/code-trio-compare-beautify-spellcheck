# Support

Need help with Code Trio?

- Read the docs in [`docs/`](docs/) and the [README](README.md).
- Run `code-trio doctor` to check your environment.
- Search [existing issues](https://github.com/aniketsoni1/code-trio-compare-beautify-spellcheck/issues).
- Open a new issue using one of the templates for bugs or feature requests.
- For questions and ideas, use
  [Discussions](https://github.com/aniketsoni1/code-trio-compare-beautify-spellcheck/discussions).

This is a community project maintained on a best-effort basis. There is no
paid support tier.
